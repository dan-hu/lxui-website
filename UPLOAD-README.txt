芝诚官网（纯静态站）上传说明
====================================

一、本站为纯 HTML/CSS/JS 静态网站，任何虚拟主机、对象存储、Nginx 均可直接托管。

二、上传方法（虚拟主机 FTP）
  1. 将本目录下的全部文件（index.html、6 个页面和 assets 目录）上传到
     虚拟主机的网站根目录（通常是 wwwroot / public_html / htdocs）。
  2. 确保首页文件名为 index.html（默认已如此）。
  3. 浏览器访问绑定的域名即可。无需数据库、无需任何服务端环境。

三、链接状态（2026-11-10 更新）

  https://www.lxui.com（共 13 处：页头 + 页脚每页 2 处、首页客户墙备注 1 处），
  已替换完成，上传后即生效，无需再做修改。
  后续如域名变更，在本目录 6 个 HTML 文件中搜索 www.lxui.com 批量替换即可。

五、部署方式：FTP 与 Git 均可
  方式 A（FTP）：按「二、上传方法」把全部文件上传到网站根目录即可。
  方式 B（Git，推荐）：
    1. 本目录已初始化 Git 仓库（main 分支，含首次提交）。
    2. 服务端拿到仓库地址后：
       git remote add origin <仓库地址>
       git push -u origin main
    3. 服务端部署一般两种做法：
       a. 平台托管（Gitea/GitLab/宝塔等）：在平台里把网站根目录绑定到
          仓库，push 后自动拉取；
       b. 服务器裸仓库 + 钩子：服务端建 bare 仓库，post-receive 钩子里
          git --work-tree=/网站根目录 --git-dir=/仓库路径 checkout -f，
          每次 push 自动同步到站点目录。
    4. 以后更新页面：改文件 → git add -A → git commit -m "说明" → git push。

六、上线前检查建议
  1. 确认域名已完成 ICP 备案并绑定到虚拟主机（大陆主机未备案无法访问）。
  2. 上传后用手机和电脑分别打开首页与 2–3 个内页，确认图片与样式正常。
  3. 建议为站点配置 HTTPS 证书（虚拟主机控制台一般有一键申请 Let's Encrypt）。
